# 学术专著阅读版排版技能（Typst · 156 × 235 mm）

把**已定稿**的中文译稿 Markdown 排成交付级学术书 PDF 的一套可复用规范 + 模板 + 核验脚本。
来自一本真实学术专著（Christopher Clapham《Africa and the International System》，307 页）的完整排版实践，
踩过的坑都写进了规范。

## 排出来是什么样

- **开本** 156 × 235 mm，版心 116 × 194 mm（每面约 31 行 × 31 字）
- **页下注**：书末注全部改页下注，带圈数字**每页从 ① 起**、按注文实际所在页编号（注被挪页时正文注号跟着改）
- **页眉外侧**：偶数页「页码　书名」，奇数页「章名　页码」；章首页不排页眉、页码在页脚
- **三套页码**：前置无页码 →《译者说明》起罗马 → 正文起阿拉伯；目录页码与 PDF 书签逐条一致
- **行内原书页标** `[N]`：与正文同字号随文排，便于读者对照原书索引
- **结构件**：编扉页、章/节排式、自动目录（点线 + 右对齐页码）、PDF 书签、参考文献悬挂缩进、索引双栏、译名对照表（拼音排序）
- **字体**：宋体 + Times New Roman + 华文中宋（粗宋）+ 楷体 + MS Mincho（带圈注号），全部真实嵌入、无回退

## 快速开始

```bash
# 1) 把这个目录放进你的 skills 目录（或用软链接）
# 2) 项目里：
cp assets/版式模板_156×235.typ              项目/工作文件/版式.typ
cp assets/版式参数_156×235.json             项目/工作文件/       # 名字不要改，模板按名读取
cp examples/排版配置_示例.json              项目/工作文件/排版配置.json   # 改路径与标题
cp scripts/build_typ_参考实现.py            项目/工作文件/build_typ.py

# 3) 转换 + 编译
python build_typ.py 排版配置.json             # → 正文.typ
python -c "import typst; typst.compile('正文.typ', output='成品.pdf', root='.',
           font_paths=['C:/Windows/Fonts'], sys_inputs={'版式':'156×235'})"

# 4) 核验 + 目视抽看
python scripts/核验_阅读版.py 成品.pdf -o 核验报告.txt
```

## 目录结构

| 路径 | 内容 |
|---|---|
| `SKILL.md` | 技能入口：何时用、五步执行、硬规则、六件最容易翻车的事 |
| `reference/排版规范.md` | **完整规范**（13 节）：版式数值、字体、标题层级、页码页眉、脚注实现、行内页标、目录书签、前后置结构、封面查找、主稿清理清单、核验清单、Typst 0.15 踩坑清单 |
| `assets/版式模板_156×235.typ` | Typst 版式本体（实测通过），文件头列了每本书要改的地方 |
| `assets/版式参数_156×235.json` | 版式数值（开本、边距、字号、行距、下沉行数） |
| `assets/封面模板.typ` | 满版原书封面函数（须在 `#show: book.with(...)` 之前调用） |
| `scripts/build_typ_参考实现.py` | Markdown → Typst 转换器（脚注按页编号、首见人名楷体、中文引号、书目/索引/对照表等） |
| `scripts/核验_阅读版.py` | 8 项机械核验：页面尺寸、嵌入字体、每页注号连续性、实测行距、空白页、目录 vs 书签、越界、图片 |
| `examples/排版配置_示例.json` | 配置字段示例（含注释性键名） |

## 依赖

- **Typst 0.15**（Python 包 `typst`，无 CLI）
- **Python 3.10+**，`pymupdf`（核验与渲染）
- Windows 自带字体：SimSun、Times New Roman、STZhongsong、KaiTi、FangSong、MS Mincho
- 任何覆盖 ①—⑳㉑—㉟㊱—㊿ 的明朝体可替换 MS Mincho

## 已知限制

- 只做**阅读版**（不是影印版，也不复刻原书版式）；原书扉页/目录/丛书广告附页按"读者版略去页"处理。
- 原书索引若在数字化时被双栏展平成行，成品只能是"原书行序"；本技能会把纯页码续行合并回上一条，但不重排字母序。
- 转换器参考实现里带了一些单本书专有的分支（前置页结构、编扉页、缩略语表配对），换书时需按底本删改。
- 只验证过 Windows + 上述字体；macOS/Linux 需换字体名（Songti SC / Hiragino Mincho 等）。
