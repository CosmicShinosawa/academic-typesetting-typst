# 学术著作阅读版排版规范（Typst · 156 × 235 mm）

> 本文件是《学术著作翻译规范》第四节（排版）在 **156 × 235 mm 开本**上的落地做法与实测经验，
> 供本项目群所有 agent 直接遵循。规则冲突时的优先级：**用户明确要求 ＞ 规范第七节硬性禁令 ＞ 本文件 ＞ 效率**。
> 本文件只写"怎么做、怎么验"；判据（如"不得漏页""不得改译义"）以《规范》为准。

---

## 0. 一句话流程

```
译文主稿.md  --build_typ.py-->  正文.typ  --typst.compile-->  成品.pdf  --核验_阅读版.py-->  核验报告
                                        ↑
                        版式模板_156×235.typ + 版式参数_156×235.json
```

排版引擎：**Typst 0.15（Python 包）**。本机没有 `typst` CLI，用 Python 调用：

```python
import sys, pathlib
sys.path.insert(0, r"<仓库>/已翻译/Cute Accelerationism/工作文件/python_deps")   # typst 0.15.0 所在
import typst
typst.compile(
    str(src).replace("\\", "/"),                 # 注意：路径里不能有反斜杠
    output=str(pdf).replace("\\", "/"),
    root=str(base).replace("\\", "/"),           # import 的相对根
    font_paths=["C:/Windows/Fonts"],
    sys_inputs={"版式": "156×235"},              # 交给 版式.typ 选参数表
)
```

**不要**用 LibreOffice / Word 转 PDF：避头尾、标点挤压、中西文混排、行距都不达标。

## 1. 开本、版心、字号（数值即 `版式参数_156×235.json`）

| 项 | 值 | 说明 |
|---|---|---|
| 页宽 × 页高 | 156 × 235 mm | 用户指定开本；《规范》默认 140 × 203 的那套只在用户未指定时用 |
| 页边距 | 上 23 / 下 18 / 左 20 / 右 20 mm | 版心 116 × 194 mm |
| 正文 | 10.5 pt（五号），行距 **17.5 pt** | 约 31 行 × 31 字/面 |
| 脚注 | 9 pt（小五），行距 **13 pt** | 见第 5 节 |
| 章标题 / 节标题 | 15 pt / 14 pt，居中 | 宋体加粗（实际用粗宋，见第 2 节） |
| 编标题 | 17 pt，居中，下沉 9 行 | 单独一页 |
| 章首下沉 / 标题后空行 | 3 行 / 4 行 | 《规范》规定值 |

行距一律写"相邻两行基线的距离"，不写"倍数"；"空 N 行"= 正常行间空白之外再加 N 个正文行距。

## 2. 字体（Windows 实测）

| 用途 | 字体 | 文件名 |
|---|---|---|
| 正文、脚注中文 | 宋体 SimSun | `simsun.ttc` |
| 西文与数字 | Times New Roman（常规/粗/斜/粗斜） | `times*.ttf` |
| **粗宋**（标题、`**bold**`） | **华文中宋 STZhongsong** | `STZHONGS.TTF` |
| 中文强调、首见人名 | 楷体 KaiTi | `simkai.ttf` |
| 大段引文 | 仿宋 FangSong | `simfang.ttf` |
| **带圈注号** ①—㊿ | **MS Mincho** | `msmincho.ttc` |

- Windows 没有 Songti SC Bold（Apple 字体）。**粗宋用华文中宋代替**，并在交付说明/排版记录里写明。
- SimSun 只有 ①—⑩；注号到 ⑳、㉑—㉟、㊱—㊿ 时若硬用 SimSun 会回退成"11""21"这种两数字，**必须**指定 MS Mincho（或任何覆盖 U+246A/U+3251/U+32B1 段的中日明朝体）。
- 交付前必须查 PDF **实际嵌入**的字体清单，出现意外字体即为"回退"，要找到缺字处改字或换字体。

## 3. 标题层级与排式

Markdown → Typst 的固定映射（主稿约定）：

| MD | 含义 | 排式 |
|---|---|---|
| `#` | 书名 | 只用于书名页，正文里不排 |
| `##` | 编 / 一级部分（译者说明、致谢、缩略语表、参考文献、索引、译名对照表、结语） | 章标题排式，另页起；**编**用一级标题 + 编扉页排式 |
| `###` | 章 | 章标题排式，另页起，下沉 3 行，标题后空 4 行 |
| `####` | 节 | 节标题 14 pt 居中，前 1 行 / 后 0.5 行 |
| `#####` | 小标题 | 11 pt 居中（默认 10.5 pt 左对齐也可） |

做法要点：

1. **编扉页**：转换器把 `## 第X编…` 输出为 `#parthd[...]`（内部是 level 1 的 heading），版式按"编"排：另页、居中 17 pt、下沉 9 行、不排页码；后接的 `### 第一章` 必须再另页起。
2. **第一编首页改用阿拉伯页码 1**：在 `#parthd` 之前、`pagebreak` 之后，由转换器在**文档顶层**输出
   `#set page(numbering: "1")` + `#counter(page).update(1)`。
   ⚠ 这两句不要写在 `parthd()` 函数体里——`set page` 在函数体内只作用于该块，不会延续到后面。
3. 页码与原书同步（第一编 = 原书 p.1）的好处：行内页标 `[N]` 可直接当原书页码用，读者对照索引方便。
4. 无"编"的书：删掉 parthd，`##` 直接当章标题用，页码从第一章起算。

## 4. 页码与页眉

- 位置：**页眉外侧**（偶数页在左、奇数页在右）；偶数页「页码　书名」，奇数页「章名　页码」。
- 体系：
  1. 封面、书名页、版权页、原书 I—VI 等前置页：**无页码**；
  2. 《译者说明》起 → 罗马数字 `i, ii, iii…`（含目录）；
  3. 第一编扉页 → 阿拉伯 `1` 起，连续编到书末（含参考文献、索引）。
- 章首页（及编首页）：**不排页眉**，页码移到**页脚居中**；编扉页连页码也不排。
- 页眉短题取"章"标题本身，**不得超过 18 字、不得转行**；超长时在配置里另给短题（转换器会报警，报警必须处理干净）。
- 页眉取标题的实现：`query(heading).filter(h => h.level <= 3)`，然后取"当前位置之前、页数最大"的那一个。

## 5. 脚注（书末注改页下注）

- 正文注号：**上标**、带圈、字号约 0.62 em，紧贴前字（用 U+2060 WORD JOINER 连接，保证不出现在行首/页首）。
- 注区注号：与注文同为小五、**在基线**、后空 0.5 em；每条首行缩两字，续行顶格。
- **每页从 ① 起**，且按"注文实际排在哪一页、该页第几条"编号——注文被排版程序整条挪到下页时，正文注号要跟着改号，保证同页不重号。
  实现（模板已内置）：

  ```typst
  #let fn-index-map() = {
    let by = (:)
    for m in query(<fnid>) {
      let k = str(m.location().page())
      by.insert(k, by.at(k, default: ()) + (m.value,))
    }
    ...
  }
  #let fn(id, body) = {
    box(context super(typographic: false, baseline: -0.45em, size: 0.62em, circled(entry-index(id))))
    footnote(numbering: (..n) => none,
      [#metadata(id)<fnid>#context circled(entry-index(id))#h(0.5em)#body])
  }
  ```

- 脚注分隔线：正文宽 25%、0.4 pt。
- 注内**不要**再出现"原注 N""（原书第 N 页）""原文/译文"这类对照信息——它们属于映射表，不进读者版。
- 多行写法的注（MD 里缩进 4 格的续行）：若上一行以 `-` 结尾且下一行小写开头，判为**断词连字符**，去连字符直接拼接（`Devasta-`+`tion`→`Devastation`）；否则用一个空格接续。

## 6. 行内页标 `[N]`

- 原书换页处随文排 `[12]`：与正文同字号同颜色，数字 Times、方括号宋体，**不上标、不放页边、不压正文**。
- 标题、目录、书签里不得出现页标。
- 2026 版 `版式模板` 里：`show regex("[\[\]]"): set text(font: "SimSun")` 已处理方括号字形。
- 若排版前发现页标单独成段、挂在段尾、卡在标题行，**先改主稿**再重排（属主稿缺陷，不是排版问题）。

## 7. 目录与书签

- 由标题**自动生成**，收"编、章、节"三级（`目录收录层级` = 4）；页眉、页标、小标题不进目录。
- 卷首原书目录被取代时，MD 里留 `## 目录` 占位并作"读者版略去页"，由转换器在指定标题（如 `## 致谢`）前插入 `#toc()`。
- 条目排式：编、章加粗，节点线连接、页码右对齐；节左缩两字。
- **页码必须按目标页的实际编号显示**（前置罗马、正文阿拉伯）。Typst 默认 `it.page` 会按"目录所在页的编号方式"去格式化，导致正文页码显示成 `ii`、`cl` 这种罗马数字——必须自绘条目：

  ```typst
  show outline.entry: it => context {
    let loc = it.element.location()
    let n = counter(page).at(loc).first()
    let body-start = query(heading).filter(h => h.level == 1).first().location()
    let label = if loc.page() < body-start.page() { numbering("i", n) } else { numbering("1", n) }
    ... link(loc, grid(columns: (auto, 1fr, auto), align: horizon, 标题, it.fill, label))
  }
  ```

  （`outline.entry` 在 0.15 里只有 `level / element / fill` 三个字段，**没有** `body`、`page`；标题取 `it.element.body`。）
- 交付前把目录页码与 **PDF 书签目标页**逐条对照（偏移应为常数）；书签层级 = 编/章/节。

## 8. 前置页与书末

### 前置（原书结构照排，均无页码）

| 页 | 内容 | 排式函数 |
|---|---|---|
| I | 内容简介 / 护封文字 | `fp-blurb`（左对齐、10 pt、首行缩进两字） |
| — | 原书空白页 | 略去（不排） |
| III | 丛书页（丛书名、编委会、丛书说明） | `fp-series`（名单居中）+ `fp-series-note`（说明文字通栏） |
| IV | 丛书书目 | `fp-list`（小字、行距紧） |
| V | 书名页 | `fp-title(书名, 副题, 作者, 单位, 出版社)` |
| VI | 版权页 | `fp-copy`（8.5 pt、**照录原文、不译**） |

然后才是《译者说明》（罗马页码起点）→ 目录 → 致谢 → 缩略语表 → 正文。

- 前置页在 MD 里是"页标 + 逐行"的格式；**短行各占一行**（`#linebreak()`），**长行（≥40 字）单独成段**（`#parbreak()`）；丛书页里 ≥100 字的那段说明要拆出来通栏排，否则会和居中名单混在一起。
- 原书目录、书末丛书广告附页一律"读者版略去页"。

### 书末

- **参考文献**：9 pt、悬挂缩进 2 字、不两端对齐；照录原文（只译分节标题）。
- **索引**：9 pt、**双栏**（`columns(2)`），照录原文；原书双栏若在数字化时被逐行展平，至少要把"纯页码续行"合并回上一条。
- **译名对照表**：每条一行"中文译名　原文"，转行悬挂两字；**按中文译名的汉语拼音排序**（`pypinyin.lazy_pinyin`，同一拼音再按字序）；人名写核实过的全名，书刊名斜体。

## 9. 封面

- **必须用原书封面**（印有封面设计的那一页），不是扉页、书名页，也不得用自制色块顶替。
- 查找顺序：出版社官网（cambridge.org 的 `assets.cambridge.org/.../large_cover/*.jpg`）→ Google Books 封面接口（`books.google.com/books/content?id=…&printsec=frontcover&img=1&zoom=4`）→ Open Library Covers → archive.org 扫描本首页（**必须目视确认首页确实是封面**后才可用）。网络受阻时可走 `web.archive.org` 快照取原字节。
- 拿到图后：裁掉扫描黑边（PIL 裁 4–6 px），`image(…, width: 156mm, height: 235mm, fit: "cover")` 满版排。
- 封面页必须单独设页面参数：`set page(width: 156mm, height: 235mm, margin: 0mm, numbering: none)`，且**该函数要在 `#show: book.with(...)` 之前调用**，否则 `set page` 会泄漏、把全书页边距和页码都改掉。
- 交付前渲染封面页看一眼。

## 10. 主稿排版前清理（这一步最容易漏，逐项做）

| 检查 | 典型缺陷 | 处理 |
|---|---|---|
| 占位/工作痕迹 | 「（接上行：…）」「（原书空白页）」「推定」「待核」「PDF 页序」 | 删或改成读者口吻 |
| 缩略语表 | 缩写行缺失（有中文说明没缩写）、缩写与说明挤在一行、占位行 | 补齐缩写、拆行 |
| 对照表 | 按 Unicode 排、`**粗体**` 当斜体用、同一人名两形（可保留已见形与全名两形） | 拼音重排、改 `*斜体*` |
| 注释 | OCR 残留 `$ ^{1} $`、断词连字符、续行 | 删残留、按第 5 节合并 |
| 页标 | 单独成段 / 挂段尾 / 进标题 | 移回段首或段中 |
| 表格/图片 | 主稿里的 `<table>`、`![]()` 是否都要排？ | 无跨页表时可照排；有则用 `#tbl(keep: true)` |
| 编码 | CRLF、BOM | 统一保留原样；用 ops 工具改文件时要显式写 `\r\n` |

改完主稿**必须重跑**结构检查器（如 `check_manuscript.py --final`），确认 0 错误再重排。

## 11. 核验清单（《规范》第四节（一）、第八节第 3 条）

机械核验（模板 `核验_阅读版.py` 一次跑完，写在报告里）：

1. 页数与页面尺寸（应 156.0 × 235.0 mm）；
2. 嵌入字体清单，**无意外字体**；
3. 每页注区编号是否自 ① 起连续（长注跳行可能误报，看图确认）；
4. 实测行距众数（正文 17.5 pt、脚注 13.0 pt）；
5. 半页以下空白的页清单，逐页说明（章末页、编扉页、末页属正常）；
6. 目录页码 vs 书签目标页（偏移应为常数）；
7. PDF 元数据（书名、作者）与书签层级；
8. 编译警告（尤其**"未收敛 / layout did not converge"**，否则目录页码不可信）。

目视渲染抽看（必做，写进排版记录）：**封面、内容简介、丛书页、书名页、版权页、译者说明、目录首页与末页、缩略语表、编扉页、章首页、脚注密集页、行内页标页、参考文献首页、索引首页、对照表首页、全书末页**。

## 12. Typst 0.15 踩坑清单（照这个排能省半天）

1. `query(heading.where(level: lv => lv <= 3))` **恒为空**；必须 `query(heading).filter(h => h.level <= 3)`。
2. 页眉函数里把局部变量命名为 `h` → `h(1.2em)` 会报 `expected function, found content`；改名 `rh`。
3. `set page(...)` 写在函数/代码块里只作用于该块；要改后续页面（切页码体系）必须写在**文档顶层**。
4. 封面 `set page(margin: 0)` 若在 `#show: book.with(...)` 之后调用会泄漏到全书 → 封面函数放最前面。
5. `outline.entry` 只有 `level/element/fill`，页码要自己算；`location` 之间**不能比大小**，要比 `loc.page()`。
6. 脚注注文不要按空格 split——多个注段用 U+2003 之类的专用分隔符，否则每个空格都变断行。
7. `#linebreak()` 要写在"上一行末尾"或"本行开头"统一位置，否则会漏掉一处导致两行粘连。
8. Typst 的 `import`/`image` 路径**不能用反斜杠**（`path must not contain a backslash`）；用 `.as_posix()`。
9. 目录、页眉里的 `it.page`/`counter` 必须在 `context` 里取。
10. 中西文自动间距会把 `[3]` 两侧也撑开一点；若要严格贴合，可对页标整体包 `box(...)`（一般可接受）。
